# Phase 1 Data Model: Chat-Start Session Persistence

One named type is needed: the Cosmos document (ported, lightly adapted). The
HTTP response is an anonymous object with a single `chatId` field — no DTO.

## `MoviceTrackerChatSession` (Cosmos document)

Ported from `movie-tracker-backend/src/MovieTracker.Backend/ChatSessionRepository.cs`.
The property names match the source so the Cosmos document shape is unchanged.
The ported class preserves its original misspelled type name (`Movice...`) so a
grep across the two repositories lines up.

| Property | Type | Source behaviour | This slice |
|---|---|---|---|
| `id` | `string` | Set to the `GenId()` result | Written. Equals `chatId`. |
| `PartitionKey` | `string` | Set to the same value as `id` | Written. Equals `id`. |
| `ChatHistory` | `List<Microsoft.Extensions.AI.ChatMessage>` | Caller-supplied list | Written with exactly one element: `new ChatMessage(ChatRole.System, ChatStartSystemPrompt.Text)`. |
| `FunnyFact` | `string?` | Initialised to `null` | Written as `null` (primitive type; no model import). |
| ~~`HydratedMovies`~~ | — | `Dictionary<string, MovieViewModel>?` in source, `null` at create | **Not declared on the ported class.** Field is absent from documents written by this slice. See Decision 3 in research.md. |

Partition key path: `/PartitionKey` (slice-001 provisioning; FR-007 assumption).

Validation: none in-process. Cosmos rejects documents that violate the
container's indexing or partition-key rules; those failures surface as
`CosmosException` and are mapped to 503 per FR-010.

State transitions: create-only. No updates in this slice.

## HTTP response shape

No DTO type is introduced. The endpoint returns the response via
`Results.Ok(new { chatId = session.id })`, which serializes to
`{ "chatId": "<id>" }` under ASP.NET Core's default web JSON options
(`JsonSerializerDefaults.Web`). FR-001 requires exactly this one property and
no others; the anonymous object delivers that shape without an extra named
type.

## Session identifier (`chatId`)

Generated by `ChatSessionRepository.GenId()`, copied verbatim from the source:

1. `RandomNumberGenerator.GetBytes(5)` — 5 cryptographically random bytes.
2. `Convert.ToBase64String(...)` — standard base64 (produces `[A-Za-z0-9+/=]`).
3. `.Replace('/', '~').Replace('+', '-').Replace("=", "")` — substitute `/`→`~`
   and `+`→`-`, strip `=` padding.
4. If the result contains `-` or `~`, recurse (retry generation).

Resulting ids are 7 characters, drawn from `[A-Za-z0-9]`. No in-process
collision detection (FR-009; retry is only for the rejected character set).

## Relationships

- `MoviceTrackerChatSession.id` **=** `MoviceTrackerChatSession.PartitionKey`
  **=** the returned `chatId`.
- `ChatHistory[0]` is the only entry at creation; its `Role` is `System` and
  its text is `ChatStartSystemPrompt.Text` verbatim (FR-003).
