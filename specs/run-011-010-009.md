# Run Slices 011, 010, 009: Autonomous Runner

Run in Claude CLI from `C:\projects\dev\movie-tracker-api`.
Runs three slices, one after another, each as its own branch and PR. Do not ask the owner anything except for the hard stops at the end.

Order: `011-local-azure-config` -> `010-eval-score-fixes` -> `009-budget-alert`.

## Workflow for EACH slice (this runner wins over any "no commit / no git / owner creates branch / do not merge / stop and report at the end" line in the slice prompts)

1. Sync: switch to `main`, pull, confirm the working tree is clean (untracked `specs/` prompt folders are fine).
2. Create the slice branch from `main` (names above).
3. Do the work exactly as the slice prompt says (`specs/<slice>/prompt.md`), including its local Codex reviews (max 6 rounds per review).
4. For 011 and 010: run the eval locally (`dotnet run --project MovieTracker.Evals`, no `set` commands after 011). Keep the final `results/last-run.json` in the commit. Record the total.
5. Commit and push. Open a PR to `main`: what changed, why, eval totals (before -> after) where relevant.
6. GitHub Codex review: comment `@codex review`, wait, answer every comment (fix, or reply with a short reason), push, request again. Loop until approved with no open comments, max 6 rounds. All PR checks must pass (`Validate Bicep`, `What-If` with no unexpected delete or replace).
7. Merge the PR. Wait until the workflows on `main` triggered by the merge finish green.
8. Go to the next slice (back to step 1).

## Global rules

- Git from Windows only. Do not touch `.gitignore`.
- Commit messages and PR text: no Claude attribution (no `Co-Authored-By`, no `Claude-Session`, no "Generated with Claude Code", no mention of Claude).
- Temp files only in `C:\projects\temp`; delete them when done.
- Commit only the current slice's `specs/<slice>/` folder with that slice; leave the other prompt folders untracked.

## Hard stops (contact the owner, then stop)

- A local Codex review or the GitHub Codex loop is not approved after 6 rounds.
- A PR check or a post-merge workflow on `main` fails and a fix inside the slice scope does not solve it.
- Anything a slice prompt lists as a stop, or a change that would go outside a slice's scope.

## Final report

PR links, Codex rounds per slice, eval totals per run, anything left open.
